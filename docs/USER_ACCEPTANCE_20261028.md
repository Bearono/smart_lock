## 入口与准备

- 页面预览：http://localhost:8080/。
- HTTPS 完整流程：https://localhost:8443/。浏览器应信任项目本地 CA；出现证书警告时不要把绕过警告记为安全验收通过。
- 管理员用户名：taylor。使用你已设置的项目密码和身份验证器验证码；本次没有重置密码、解除 MFA 或新建替代管理员。
- 登录后的同一组验证码不能再次用于开门或改密，应等待身份验证器出现下一组代码。
- 现有硬件只有树莓派与摄像头，没有实体锁/继电器。授权成功、命令受理和物理开门是三件不同的事。
- 本次连接原树莓派地址 SSH 超时；相机与人脸项目需连接恢复后再验收。离线状态和历史快照仍可检查。

## 第二轮：核对真实业务

建议使用独立的测试访客和测试普通账号，避免改变现有成员的权限。以下操作由你在页面自主执行。

| 勾选 | 操作 | 验收标准 |
| --- | --- | --- |
| ☐ | 创建测试访客 | 新凭证只在必要的位置显示，列表正确显示期限和次数；不要把凭证截图公开 |
| ☐ | 撤销该访客，在 `/guest` 验证 | 撤销后拒绝请求，不产生有效开门授权或“已开门”提示 |
| ☐ | 使用无效访客凭证 | 显示合理错误，无空白页、程序堆栈或误报成功 |
| ☐ | 给家门改名，再刷新 | 名称保存并与相应设备一致；不混淆不同设备 |
| ☐ | 审批独立测试账号并授权设备 | 只有批准且获授权的设备可访问；撤销后旧权限失效 |
| ☐ | 普通账号访问管理页面 | 页面和 API 都拒绝管理操作，不能仅靠隐藏按钮保护 |
| ☐ | 退出，再直接访问 `/dashboard` | 返回登录页；刷新或返回历史页面不能恢复已撤销会话 |
| ☐ | 改密（可选） | 原密码与新验证码正确才成功，旧会话撤销；改前确认自己能保存新密码 |
