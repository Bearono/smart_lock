# 视觉与交互

界面以家门状态、门前画面和当前操作为中心。暖白与石墨灰承载内容，蓝色表示主动作和选中态，绿色、琥珀色和红色分别表示正常、警告与错误。颜色、间距、圆角和材质统一由 `apps/web/src/shared/styles/tokens.css` 管理。

## 布局

- 导航与内容分层；首页按设备选择、画面与门锁、本次结果、最近动态排列。
- 摄像头保持原始比例，允许查看大图；接收时间明确标注，单帧照片不称作实时视频。
- 门锁上报状态与命令结果分别显示，未知结果保留查询入口，模拟执行明确标识。
- 表格在窄屏转换为可读记录，空态说明下一步，关键操作不依赖悬停。

## 材质与运动

玻璃效果用于导航、工具栏和临时控件，内容卡片保持高不透明度。`shared/material` 管理几何法线、弹簧运动、触点高光与选中项过渡；组件卸载时释放观察器、滤镜和动画。静止页面不维持动画循环，相机图像不参与折射。

支持不足时使用毛玻璃或实色。系统减少运动、减少透明度、增强对比度及强制颜色偏好优先于视觉效果。弹窗使用原生 dialog、焦点回退与键盘操作。

## 验证

`npm test` 检查弹簧稳定性、法线边界和颜色对比度；`test:browser` 检查响应式布局、文字放大和业务状态；`test:material` 检查动态效果、降级和资源释放。视觉效果不能决定认证或执行成功。

设计参考 [Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials)、[Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/) 与 [Apple Home](https://www.apple.com/home-app/)。项目使用自己的网页实现和[独立素材](assets.md)，不复制品牌代码或资产。
