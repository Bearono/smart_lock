## 设备软件镜像

验收发现原 Debian 配置使用了不存在的 `python3-dlib` 包。已改为独立构建阶段编译固定版本 dlib，补齐 wheel、make 和 C++ 工具；运行阶段统一 Python 3.12，固定 NumPy、无界面 OpenCV 与 Pillow，构建工具不进入运行镜像。官方软件源改用 HTTPS 并保留证书与签名校验。

持续集成增加 `device-image` 作业：构建后在无网络、只读容器中执行 `deploy/device_smoke.py`，验证视觉依赖加载、合成空白图检测、设备健康响应及未签名请求拒绝。2026-09-26 本机 linux/amd64 镜像构建成功；无网络、只读容器中的离线检查通过，实际加载 OpenCV 4.11.0 和 dlib 19.24.6。未映射摄像头或 GPIO。模型包使用旧资源接口，运行依赖固定 setuptools 80.9.0；其弃用提示不影响本轮检查结果。

## 交付与复现

- 统一验收入口：`python deploy/verify.py`。
- 打包入口：`python deploy/package_release.py releases/<name>.zip`；源码变动后必须重新验收。
- 包内保留源码、部署说明、测试、逐文件清单及验收日志；排除密钥、数据库、个人模板、外置识别模型、依赖目录和历史构建输出。
- 既有工作区修改保留，未替用户提交 Git 或发布远程服务。

部署入口见 `deploy/README.md`，设备驱动和故障恢复契约见 `docs/DEVICE_EXECUTION.md`。实物驱动、ARM 运行、现场识别指标及实地部署不在本轮软件验收结论内。
