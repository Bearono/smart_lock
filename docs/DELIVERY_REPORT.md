## 交付与复现

- 统一验收入口：`python deploy/verify.py`。
- 打包入口：`python deploy/package_release.py releases/<name>.zip`；源码变动后必须重新验收。
- 包内保留源码、部署说明、测试、逐文件清单及验收日志；排除密钥、数据库、个人模板、外置识别模型、依赖目录和历史构建输出。
- 既有工作区修改保留，未替用户提交 Git 或发布远程服务。

部署入口见 `deploy/README.md`，设备驱动和故障恢复契约见 `docs/DEVICE_EXECUTION.md`。实物驱动、ARM 运行、现场识别指标及实地部署不在本轮软件验收结论内。
