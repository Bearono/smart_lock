# 硬件购买建议与下单检查表

日期：2026-10-17。现有Pi 4B / 2GB，赠送摄像头型号待核对，预算尚未确定。建议先解决采集问题，再补一个能读到真实反馈的桌面门锁原型。

本文给出选型和预算占位，不代表已经采购，也不把外币官网价直接换算成国内到手价。[安全流程](SECURITY_FLOW_GUIDE_20261017.md)和[任务表](SECURITY_TASK_BREAKDOWN_20261017.md)说明这些硬件对应的验收任务。

## 1. 建议购买顺序

1. **立即做零采购定位：**确认运行版本、主采集/录入路径、白平衡和相机型号，借一只已知正常的UVC相机对照。
2. **先买固定与成像配件：**相机固定架、稳定普通白光补光、可靠排线（缺才买）。
3. **决定接实体锁后整套下单：**锁、驱动、独立电源、反馈、门磁、接线保护和门板一起规划，避免只买锁却无法安全驱动和验收。
4. **相机确认不可用再替换：**优先标准彩色CSI自动对焦模组，预算低时考虑能退换的Linux UVC相机。
5. **音频、安全芯片、新开发板等延后：**它们对目前密钥生命周期主线不是前置条件。

## 2. 相机具体怎么买

### 首选备选型号：Camera Module 3 Standard，普通彩色版

若修复通道与白平衡后现有相机仍然画质不足，建议选官方Raspberry Pi Camera Module 3的标准视角、带IR-cut版本。它有IMX708 12MP传感器和自动对焦；普通版有红外截止滤光片，NoIR版没有。官方起价25美元，国内含税/运费/渠道价格另询。

理由：现有项目已经有Picamera2/CSI路径，普通彩色和自动对焦更适合室内人脸实验。这里不承诺换相机就能提高识别或防伪准确率，换机后必须重采模板、固定测试条件并复测阈值。

下单要写清：

- Raspberry Pi Camera Module 3 Standard / Normal FoV / 普通彩色IR-cut；不是NoIR，不默认选Wide。
- Pi 4B使用标准15-pin接口和相应排线；不要误买仅适合Pi 5/Zero小接口的线。
- 配固定架/相机壳，确认安装距离与对焦范围。
- 当前推理仍可用640×480起步，不因相机12MP就全链路运行最高分辨率。

来源：[Camera Module 3官方规格](https://www.raspberrypi.com/products/camera-module-3/)、[相机接口与线缆](https://www.raspberrypi.com/documentation/accessories/camera.html)。

### 低预算替代：Linux UVC普通彩色USB相机

不指定未经实测的低价型号。购买前要求Linux免专用驱动、可输出项目能读取的640×480或720p画面、色彩正常、对焦距离合适，最好允许退换或借测。项目已有OpenCV后端，但仍需验证实际设备索引、格式、启动时间、推理内存和重连行为。

建议相机采购预留约150–350元，具体以选定型号询价为准；若继续使用赠送相机，可先不花这笔预算。

整套建议先批准约200–400元上限，明确需要哪些现有配件，再询价裁剪。Pi电源与锁具电源分开考虑，不把锁线接到Pi GPIO电源脚。

### 可核对的参考锁：DFRobot FIT0620

官方说明：9–12V、1.5A，具有状态反馈与机械应急机构；通电应少于5秒，长时间通电可能损坏线圈。可作为教学柜门式原型的参考，不等同于住宅入户门的商用门锁选型。

采购前要问清反馈触点的含义、电气类型与电压：它表示扣合、锁舌还是其他机械状态？常开/常闭怎么定义？如果不是干接点，就需隔离或电平转换。软件`read_state()`按实际反馈建立映射。

**这一类锁通常靠脉冲释放、人工关门重新扣合，不能凭LOCK命令自动把敞开的门关上。** 若课程要求可远程双向驱动的锁舌，则改选有明确接口与反馈的电机锁，并另评估H桥、限位和电源预算；不能买柜锁后伪装双向机械能力。

来源：[FIT0620产品及通电限制](https://www.dfrobot.com/product-1856.html)、[FIT0620规格与反馈示例](https://wiki.dfrobot.com/fit0620/)。

### 可核对的参考驱动：DFRobot DFR0457

官方标注逻辑输入3.3–10V，可作为匹配Pi 3.3V逻辑的MOSFET模块参考。下单前仍需核对负载额定值、端子、接地方式、默认输出及感性负载保护；不能仅看“支持树莓派”就视为整套接线已确认。继电器也可使用，但要确认3.3V触发和直流感性负载能力。

来源：[DFR0457官方说明](https://wiki.dfrobot.com/dfr0457/)、[Pi GPIO官方电气说明](https://www.raspberrypi.com/documentation/computers/raspberry-pi.html)。

## 4. 电气和软件必须一起核对

```text
Pi 3.3V GPIO → 兼容驱动的控制输入
独立锁电源 → 保险/保护 → 驱动负载回路 → 锁
锁反馈触点 → 经核对的3.3V输入电路 → Pi
门磁干接点 → 另一路3.3V输入 → Pi
```

这是逻辑关系，不能代替具体端子的接线图。是否共地或隔离由驱动方案决定；感性负载需要核对续流/浪涌保护。5V/12V反馈不可直接接入3.3V GPIO。

软件需同时具备：启动默认无动作、硬限时输出、异常退出关断、读取真实反馈、反馈超时/断线失败、执行前日志与重启去重。电锁的手动应急机构应可操作，桌面演示不要装到实际出入门上作为日常门禁。

## 5. 与密钥安全有关的硬件要不要买

目前不需要为了展示SPAKE2再买第二块Pi、TPM或安全芯片。PC上的独立进程可以承担第二实验身份；现有Pi足以运行主线协议，实际资源情况由测量判断。

安全芯片可在后续保护设备私钥或长期材料，但需要驱动、密钥槽位、运算接口和生命周期适配。买一个模块不会自动让现有共享秘密协议变成SPAKE2+、mTLS或具有抗物理提取能力。当前更值得投入的是独立凭据、轮换/退役和反馈验收。

若希望增加低成本“终端安全”展示，可在外壳装一个干接点防拆开关，软件明确记录真实触发与恢复；先保证主线，不把防拆开关当成安全芯片。

## 6. 音频硬件：确认选做后再买

若组会决定扩展真实声学密钥分发，可买Linux支持的USB音频输入/输出、麦克风及小扬声器，预留约100–200元。先用电脑现有扬声器作发送端、Pi作接收端，避免同时购两套。

购买前核对48kHz单声道录音支持及Linux实际识别情况。真实测距离、噪声、采样时钟偏差和丢包；CRC只检错，恢复出的票据/信封必须继续验签/认证和防重放。当前没有此项必做要求，建议延期。

来源：[Raspberry Pi官方音频选型](https://pip-assets.raspberrypi.com/categories/1259-audio-camera-and-display/documents/RP-008124-WP-1-Choosing%20an%20Audio%20option.pdf)。

## 7. 三档预算决策

| 方案 | 建议范围 | 可交付内容 |
| --- | --- | --- |
| 最省：沿用现有硬件 | 先不买主器件，必要支架/白光另核价 | 摄像头修正、设备密钥交换、生命周期、实机授权与安全实验；实体执行仍明确缺失 |
| 推荐：增加门锁闭环 | 原相机可用时约200–400元预留 | 桌面小门板、真实锁反馈与门磁、正常及故障执行证据 |
| 推荐+换相机 | 在上一档基础上另预留150–350元 | 颜色和对焦更可控的人脸采集，换机后重采与复测 |

预算先定上限，再询价；不要同时把换相机、音频、开发板和安全芯片全开。型号官方规格已在2026-10-17查询，国内实际成交价、库存和到货时间仍需采购负责人确认。

## 8. 复制给采购负责人的需求

请先询价一套可装在桌面小门板上的低压锁原型：带真实状态反馈与手动释放的9–12V教学锁、明确支持3.3V控制且适合感性负载的驱动、匹配独立电源、门磁干接点、按钮/LED、接线保护与安装件。要求供应方给出电流、通电时限、反馈触点定义和接线资料。整套目标预算200–400元，未确认型号参数前先不下单。现有摄像头先排查；若确需更换，另询Camera Module 3 Standard普通彩色IR-cut版和Pi 4标准15-pin排线。
