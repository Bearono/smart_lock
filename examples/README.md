# 独立实验与历史示例

这些目录用于教学追溯，不是当前门锁的功能入口，也不进入 Android APK 或运行镜像。

| 目录 | 内容 |
| --- | --- |
| [android_audio](android_audio/README.md) | 从手机主应用迁出的 Java 编解码、密钥实验及互操作测试 |
| [audio_lab](audio_lab/README.md) | 可选电脑音频控制台入口 |
| [legacy_crypto](https://github.com/Bearono/smart_lock/tree/main/examples/legacy_crypto) | 不安全的早期密码示例，仅供阅读 |
| [legacy_cv](https://github.com/Bearono/smart_lock/tree/main/examples/legacy_cv) | 早期独立视觉实验 |

当前交付范围见 [验收说明](../docs/acceptance.md)。历史密码与 CV 示例不进入默认源码发布包；保留源码不代表继续开展音频实机验收。
